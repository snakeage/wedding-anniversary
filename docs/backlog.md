# Backlog

Work lives in **[GitHub Issues](https://github.com/snakeage/wedding-anniversary/issues)**, not in a second list here.

## How we work

1. Filter by label **`now`**. There must be **exactly one** open issue with `now`.
2. Do that issue (and only that) until it is closed.
3. Close the issue, then put `now` on the next open issue: **`p0` before `p1` before `p2` before `p3`**.
4. Do not copy this queue into Notion, a Google Doc, or a long markdown table — it will drift.

Priorities: `p0` first live sale, `p1` second client / storefront, `p2` trust, `p3` self-serve scale (one epic, not 18 skin tickets).

## Agent

See `AGENTS.md`. Before coding: say which issue is `now`. If sales are blocked by something that is not `now` (e.g. RSVP still not stored), **propose** moving `now` — do not silently start another catalog skin.
