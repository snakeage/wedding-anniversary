## Организатору

### 1. Войти

Откройте `/login` → **Открыть бота**. В Telegram придёт меню и кнопка «Открыть кабинет». Login Widget на той же странице — запасной путь.

Без SMS и без пароля в ссылке. Аккаунт = ваш Telegram.

В боте также:

| Команда | Что делает |
| --- | --- |
| `/start` | Меню: кабинет, события, помощь |
| `/events` | Список ваших приглашений и статусы (черновик / на проверке / опубликовано) |
| `/cancel` | Отменить ожидание чека, если нажали «Отправить чек в бот» по ошибке |
| `/help` | Краткая памятка |

Чек по-прежнему присылается **фото или PDF** в этот чат — отдельной команды «отправить скрин» нет: бот принимает файл, когда ждёт чек.

### 2. Создать приглашение

В кабинете → **Создать приглашение**.

- **Адрес ссылки** (`slug`) — латиница и дефис, например `anna-dr`. Гости откроют `сайт/этот-адрес`. После создания его **нельзя** сменить. Адреса `sofia`, `ivan-maria`, `kira` и `olga-nikita` заняты демо.
- Шаблон: Quiet luxury (день рождения), Paper envelope (свадьба), Dark editorial (вечерний гала) или Garden daylight (свадьба в саду или за городом).
- Имена, дата (московское время), площадка, ссылка из Яндекс.Карт или координаты.
- Фото необязательно. Шаблон сразу подставляет свои атмосферные кадры и подписи — их можно оставить, заменить по одному своим файлом (JPEG / PNG / WebP до 4 МБ) или убрать. Без снимков блок на странице не появится. Надпись и заголовок блока тоже можно править.

Создание принимает [условия сервиса](https://wedding-anniversary-seven-tau.vercel.app/terms). Событие появляется как **черновик**.

### 3. Черновик

| Кто | Что видит |
| --- | --- |
| Вы, из кабинета | Предпросмотр с водяным знаком «Черновик». RSVP выключен. |
| Гость по ссылке | 404, пока не активируете. |
| Изменить | Тексты, место, фото. Снятие или замена снимка убирает старый файл из хранилища; без фото блок на странице не появляется. |
| Срок | Если 14 дней нет правок и нет оплаты — напоминание в бот. За 2 дня до снятия — предупреждение: допишите и оплатите. На ~30-й день без оплаты черновик, фото и адрес ссылки снимаем. Оплаченная страница по-прежнему живёт до даты события и ещё 10 дней. |

### 4. Оплатить и открыть гостям

Разовый платёж **5 000 ₽**. Страница и RSVP — до даты события и ещё **10 дней** после.

1. Реквизиты СБП в карточке события (банк, телефон, получатель).
2. Переведите сумму. **Комментарий к переводу оставьте пустым** — подтверждение по чеку в боте, не по полю в банке.
3. **Отправить чек в бот** → пришлите **фото или PDF** квитанции. Если нажали по ошибке — `/cancel`.
4. Статус станет «На проверке». Обычно 1–2 часа, до 24 часов ночью или при сбоях. Бот напишет, когда страница откроется.
5. Кнопка «Я отправил(а) чек» только помечает ожидание в кабинете; без файла в боте активировать нельзя.

До активации можно отказаться, написав в бот. После активации возврата нет: страница уже открыта гостям.

### 5. После публикации

- Шлите гостям ссылку `/{slug}`.
- **Ответы гостей** в кабинете, выгрузка CSV, и одно сообщение в бот.
- Правки текстов и фото по-прежнему из **Изменить**.

## Админу (ты)

Это не кабинет организатора. Ты подтверждаешь оплату в Telegram и при нужде смотришь все RSVP.

### Один раз

1. Напиши **своему** боту (`@invitation_cabinet_bot`) `/start` — иначе он не сможет прислать чек в личку.
2. `TELEGRAM_ADMIN_CHAT_ID` — твой числовой Telegram id (не id бота). Уже стоит в Vercel Production и Preview.
3. Реквизиты СБП (`SBP_PHONE` и остальные) должны быть в Vercel, иначе в кабинете пусто.

### Чек

В личку бота приходит фото/PDF:

- событие `/{slug}`
- имя организатора
- сумма 5 000 ₽
- кнопки **Подтвердить (5 000 ₽)** / **Отклонить**

**Подтвердить** → событие `active`, организатору ссылка на страницу.  
**Отклонить** → снова черновик, организатору сообщение проверить квитанцию.

Кнопки срабатывают только из твоего чата с ботом.

### RSVP всех событий

На `/login` внизу: **Вход для администратора по паролю** (`RSVP_ADMIN_SECRET`). Это не вход организатора: попадаешь в `/rsvp-list` и видишь ответы, в том числе демо. Организатор из кабинета видит только свои события.

### Чего нет

Из бота нельзя править чужие тексты и фото — только активация. Свой тестовый кабинет: обычный вход через Telegram, как организатор.

### Профиль бота (BotFather)

Код отвечает на `/start` (меню и кабинет), `/events` (статусы приглашений), `/cancel` (сброс ожидания чека), `/help` и на фото/PDF чека после `/start pay_<slug>` из кабинета. Меню, описание и webhook ставит `npm run telegram:webhook` (нужны `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `NEXT_PUBLIC_SITE_URL`).

Картинку и домен виджета API не ставит — это вручную в [@BotFather](https://t.me/BotFather):

1. `/mybots` → `@invitation_cabinet_bot`
2. **Edit Bot → Edit Botpic** — файл [`public/brand/bot-avatar.png`](../public/brand/bot-avatar.png) (квадрат, кружок в чатах). Шли **как фото**, не как файл.
3. **Edit Bot → Edit Description Picture** — файл [`public/brand/bot-welcome.png`](../public/brand/bot-welcome.png) (**640×360**, блок «Что умеет этот бот?» до Start). Тоже как фото.
4. **Bot Settings → Domain** (`/setdomain`) — **только хост, без `https://` и без `/`:**
   `wedding-anniversary-seven-tau.vercel.app`
5. По желанию: **Edit Name**. Username не меняй.

Сайт в браузере всё равно открывается как `https://…`. `https://` нужен в других местах, не в BotFather:

| Куда | Как писать |
| --- | --- |
| BotFather `/setdomain` | `wedding-anniversary-seven-tau.vercel.app` |
| Vercel `NEXT_PUBLIC_SITE_URL` | `https://wedding-anniversary-seven-tau.vercel.app` |
| Ссылки гостям, webhook | тоже с `https://` |

После смены домена Vercel снова прогони `npm run telegram:webhook`.
